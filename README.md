# NeetCode 150 — Pattern-Based DSA

> **Goal:** Master DSA patterns, not memorize 150 solutions.

This repository reorganizes the NeetCode 150 problem set around the **underlying problem-solving patterns** used in coding interviews.

## How to use this repository

For every problem:

1. Identify the pattern before coding.
2. Explain the brute-force approach.
3. Derive the optimal approach.
4. Implement it in Java.
5. Record time and space complexity.
6. Re-solve it later without looking at the solution.
